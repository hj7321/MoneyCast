# MoneyCast 모바일

저장소 루트에서 `npm install` 후 `npm run mobile` 또는 이 폴더에서 `npm start`로 Metro를 실행합니다. Expo SDK 54와 호환되는 Expo Go 또는 개발 빌드에서 QR을 열 수 있습니다. 최신 Expo Go가 SDK 54를 지원하지 않으면 SDK 54용 Android Expo Go 또는 개발 빌드를 사용하세요. Android 에뮬레이터는 `npm run android`, macOS의 iOS 시뮬레이터는 `npm run ios`를 사용합니다. iOS 네이티브 빌드는 macOS/Xcode가 필요합니다.

`apps/mobile/.env.example`를 `.env`로 복사하고 `EXPO_PUBLIC_API_URL`에 백엔드 주소를 입력하세요. 배포된 뉴스 API는 `https://moneycast.vercel.app`입니다. 로컬 Android 에뮬레이터에서는 `http://10.0.2.2:8787`, 실제 기기에서는 같은 네트워크의 개발 PC IP를 사용합니다. 실제 기기에서 로컬 서버에 접근하려면 서버를 `HOST=0.0.0.0`으로 시작하고 해당 포트의 로컬 접근을 허용해야 합니다. 환경변수 수정 후 Metro를 다시 시작하세요.

공개 API 주소만 앱에 포함됩니다. `MARKETAUX_API_TOKEN`, 선택적 게이트웨이의 `NEWS_API_KEY`, AI 키(`GEMINI_API_KEY`, `CLOUDFLARE_API_TOKEN`)는 루트 서버 `.env`나 서버 환경변수에만 설정합니다. 웹과 앱은 같은 서버의 출처 결합(Marketaux·GDELT)과 AI 교차 판단 결과를 사용합니다. API 주소 미설정, 키 미설정, 인증·이용 권한 오류, 호출 제한, 응답 오류와 근거 부족을 각각 표시하며 예시 뉴스를 넣지 않습니다. 새로 고침이 실패하면 이번 앱 실행 중 받은 마지막 정상 결과를 **이전 결과**로 표시합니다. 뉴스 탭을 처음 열 때만 요청을 시작하고 이후 탭 전환 시 상태를 유지합니다. 기사 언어·제공자 감성 분류·AI 합의·잠정·판단 유보·미분류·원문 출처와 핵심 요약(AI 요약 또는 매체 설명)을 표시합니다. 두 AI가 모두 이 회사 기사가 아니라고 본 기사는 **관련성 낮음**으로 집계에서 빼고, 목록 아래 **관련성 낮은 기사 N건 보기**로 펼칩니다. 점수가 있어도 두 AI가 정반대 방향으로 합의한 기사는 AI 합의로, 점수와 AI 판단이 엇갈린 기사는 판단 유보로 표시합니다. GDELT는 예약 수집 때만 조회해 출처 상태에 그렇게 표시하며, 뉴스 감성 점수는 상승 확률이 아닙니다. 응답에 AI 분류(`classificationMethod: "llm"`), 관련성 표시(`aiRelevance`), 출처 상태 `skipped`가 들어가므로 이전 개발 빌드는 새 응답을 거부할 수 있습니다. 앱을 다시 빌드하거나 Metro를 재시작해 최신 코드를 사용하세요. 서버 설정과 무료 한도는 [루트 안내](../../README.md#뉴스-연결과-환경변수)를 확인하세요.

계산은 `@moneycast/core`를 웹과 공유합니다. 월말 납입과 연 유효수익률의 월 전환을 사용하며 원 단위는 최종 표시 시 반올림합니다. 세금·수수료·물가상승률은 제외하고 수익률은 사용자가 입력한 가정입니다. 차트는 작은 화면에서 읽기 쉬운 선택 가능한 월별 표본 막대로 구현하고 선택 시점의 자산·원금을 숫자로 제공합니다.

월 수익률은 `r = (1 + 연 수익률 / 100)^(1/12) - 1`이고, 매월 `다음 자산 = 이전 자산 × (1 + r) + 월 납입액`으로 계산합니다. 금액은 0~1조 원, 연 수익률은 -100% 초과~100% 이하입니다. 목표 기간은 **1~600개월(50년)을 정수 개월로 입력**하며 기본값은 **60개월(5년)**입니다. 화면에는 `13개월 → 1년 1개월`처럼 읽기 쉬운 기간을 함께 표시하고, 공용 계산 함수에 전달할 때만 `개월 / 12`로 환산합니다. 빈 값·0개월·음수·소수 개월·601개월 이상·유효하지 않은 숫자·안전 정수 범위를 넘는 계산 결과는 오류로 표시합니다. 목표 0원은 목표 미설정입니다. 목표 유형은 웹과 같은 자유 목표·내 집 마련·자동차·여행이며 예시 금액(5천만 원·3억 원·4천만 원·1천만 원)으로 시작합니다. 유형마다 목표 금액을 정하는 데 필요한 칸만 보여 주고(자유 목표: 이름·금액 정하는 방법·항목, 내 집 마련·자동차: 모으려는 금액·가격·대출 또는 초기 자금, 여행: 여행지·총액 또는 인원·박·일·항목 금액), 목표 금액과 그 출처(예시·직접 입력·상세 계산·미정)는 웹과 같은 공용 규칙(`packages/core/src/goals.ts`)으로 계산합니다. 지역·주택 유형·차종·부대비용 같은 선택 항목은 웹에서만 입력합니다. 자유 목표 설명은 웹과 같은 규칙으로 기기에서 정리하고 같은 질문을 보여 주며, 서버에서 AI 정리를 켰고 `EXPO_PUBLIC_API_URL`이 있을 때만 **AI로 다시 정리하기**를 보여 줍니다.

`npm run typecheck`는 앱 TypeScript 검사, `npm run export`는 iOS·Android JavaScript 번들 생성입니다. 번들 생성은 실제 기기에서의 실행이나 스토어 제출을 대신하지 않습니다. 이 MVP에는 서명, 앱스토어 자격 증명, 네이티브 배포 자동화를 포함하지 않습니다.
