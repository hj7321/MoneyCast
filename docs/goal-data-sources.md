# 목표 금액과 공식 데이터·세율 검토

작성일 2026-10-28. 목표 유형별 입력 작업(3단계)에서 검토했지만 **구현하지 않은** 두 항목, 세율 기반 부대비용 추정과 공식 데이터 연동의 근거와 조건을 정리합니다. 이 문서에는 아래 세 표기를 씁니다.

- **[확인]**: 공식 출처에서 직접 읽은 내용입니다.
- **[확인 필요]**: 아직 확인하지 않아 구현 전에 확인해야 하는 내용입니다.
- **[제안]**: 도입할 경우의 설계안입니다.

현재 목표 금액은 사용자가 입력한 금액과 그 합·차·비율로만 만듭니다. 이번 작업에서도 외부 시세·통계 API를 호출하지 않았습니다.

## 1. 세율 기반 부대비용 추정: 보류

### 확인한 공식 출처

**[확인]** 2026-10-28에 국가법령정보센터(`www.law.go.kr`)의 조문 화면을 조회했습니다. 대상 법령은 「지방세법」 [시행 2026. 1. 1.] [법률 제21308호, 2025. 12. 31., 일부개정]입니다.

| 조문 | 읽은 내용 |
|---|---|
| 제11조 제1항 제8호(유상거래 주택) | 취득당시가액이 6억 원 이하이면 1천분의 10, 9억 원을 넘으면 1천분의 30입니다. 6억 원 초과 9억 원 이하는 별도 계산식에 따른 세율이며, 소수점 이하 다섯째 자리에서 반올림합니다. **계산식은 조문 화면에서 텍스트로 확인하지 못했습니다.** |
| 제12조 제1항 제2호 가목(차량) | 비영업용 승용자동차는 1천분의 70, 경자동차는 1천분의 40입니다. |
| 제13조의2(법인의 주택 취득 등 중과) | 법인, 조정대상지역의 1세대 2주택(일시적 2주택 제외), 조정대상지역 밖의 1세대 3주택 등은 제11조 제1항 제8호 대신 중과 세율을 적용합니다. 조정대상지역은 「주택법」 제63조의2에 따른 지역입니다. |

### 구현하지 않은 이유

- 6억 원 초과 9억 원 이하 구간의 계산식을 확인하지 못했습니다. 이 구간을 추정해서 넣으면 근거 없는 수치가 됩니다.
- 실제 세액은 기본세율만으로 정해지지 않습니다. 아래 항목은 모두 **[확인 필요]**입니다.
  - 주택 수와 조정대상지역 지정에 따른 중과: 조정대상지역은 지정·해제가 바뀌므로 기준일 관리가 필요합니다.
  - 지방교육세(「지방세법」)
  - 농어촌특별세(「농어촌특별세법」): 면적 기준 비과세가 있습니다.
  - 생애최초 주택 구입 등 감면(「지방세특례제한법」): 일몰 기한이 있습니다.
- 자동차는 기본세율 외에도 다음 항목이 결과를 바꿉니다. 모두 **[확인 필요]**입니다.
  - 경차·친환경차·다자녀 감면
  - 지역별 공채 매입
  - 과세표준 산정 방식
- 기본세율만 계산하면 중과 대상이나 공채가 있는 사용자의 부대비용을 실제보다 낮게 보여 줍니다. 이는 '근거 없는 금액을 사실처럼 제시하지 않는다'는 원칙과 맞지 않습니다.
- 그래서 부대비용은 지금처럼 사용자가 직접 입력합니다. 입력 칸 안내에는 "세금은 자동 계산하지 않아요"를 유지합니다.

### 도입한다면 필요한 조건 [제안]

1. **계산 대상을 좁힙니다.** 예를 들어 개인이 유상 매매로 취득하고, 취득 후 1세대 1주택이며, 중과 대상이 아닌 경우만 계산합니다. 사용자가 조건을 직접 확인해 체크해야만 계산합니다.
2. **세율표를 코드 상수로 관리합니다.** 법령명, 조문, 시행일, 조회일을 함께 둡니다. 법령이 개정될 때 갱신할 담당자와 확인 주기를 정합니다.
3. **포함 범위를 화면에 적습니다.** 지방교육세·농어촌특별세·감면을 포함하는지 표시합니다. 결과는 '참고 추정'으로 표시하고 사용자가 금액을 고칠 수 있게 합니다.
4. **공식 계산 결과와 대조하는 테스트를 둡니다.** 위택스 등 공식 계산기와 비교합니다. 어떤 계산기가 어느 범위까지 계산해 주는지는 **[확인 필요]**입니다.

## 2. 공식 데이터 연동 후보: 이번 범위 밖

후보 목록은 공개적으로 알려진 출처를 정리한 것입니다. 이용 조건, 호출 한도, 키 발급 절차, 데이터 형식은 이번에 확인하지 않았으므로 모두 **[확인 필요]**입니다.

| 데이터 | 후보 출처 | 쓸 수 있는 방식 [제안] | 주의할 점 |
|---|---|---|---|
| 주택 실거래가 | 국토교통부 실거래가 자료(공공데이터포털 API) | 사용자가 고른 지역의 최근 거래 금액 범위를 출처·기준 기간과 함께 참고로만 보여 줍니다. 목표 금액 칸은 자동으로 바꾸지 않습니다. | 지역 코드(법정동 코드) 기반 선택이 필요합니다. 지금의 자유 입력 시·군·구로는 연결할 수 없습니다. 면적·층·연식이 달라 개별 집값을 대신하지 못합니다. |
| 주택 가격 통계 | 한국부동산원 부동산통계(R-ONE) | 지역 가격 흐름을 참고 지표로 보여 줍니다. | 지수·평균은 개별 집값이 아니므로 목표 금액으로 쓰면 오해할 수 있습니다. |
| 소비자물가 | 통계청 KOSIS, 한국은행 ECOS | 물가상승 반영 칸 옆에 '최근 공식 물가상승률(기준 기간)'을 참고로 보여 줍니다. | 과거 값이며 전망이 아님을 표시해야 합니다. 앱이 비율을 대신 정하지 않습니다. |
| 환율 | 한국은행 ECOS, 한국수출입은행 환율 정보 | 여행 외화 예산을 원화로 환산합니다. | '시세 API를 쓰지 않는다'는 현재 원칙과 충돌하므로 도입 여부부터 결정해야 합니다. |
| 차량 가격 | 공식 공개 데이터 출처를 찾지 못했습니다. | — | 제조사 가격표는 공식 API가 아니며 트림·옵션·할인에 따라 달라집니다. |
| 여행 경비 | 관광 통계(예: 국민여행조사) | — | 평균값이라 개인의 목표 금액으로 쓰기 어렵습니다. |

### 연동할 때의 공통 원칙 [제안]

- **호출 위치와 키 관리**: 외부 데이터는 서버에서만 부릅니다. 키는 서버 환경변수에만 두고, 캐시와 호출 한도를 둡니다. 실패하면 지금처럼 직접 입력으로 계속 진행합니다.
- **화면 표시**: 출처, 기준 기간, 조회 시각을 함께 표시합니다. 사용자가 **적용**을 누르기 전에는 목표 금액을 바꾸지 않습니다.
- **평균·지수**: 개인의 목표 금액처럼 표시하지 않고, 범위나 참고 지표로만 보여 줍니다.
- **보내는 정보**: 지역 같은 조회 조건만 보냅니다. 목표 이름·설명·계산 입력은 보내지 않습니다.

## 3. 이번 작업에서 정한 것

- **시·군·구**: 자유 입력 라벨(20자)입니다. 결과의 목표 이름에만 쓰고 계산이나 외부 조회에는 쓰지 않습니다. 전국 시·군·구 목록을 관리하지 않아도 되도록 선택 목록 대신 직접 입력을 택했습니다. 실거래가와 연동하려면 법정동 코드 기반 선택 목록으로 바꿔야 합니다.
- **물가상승 반영**: 사용자가 입력한 비율(0~20%)만 씁니다. 공식 통계를 기본값으로 채우지 않았습니다.
